# Release 历史材料说明

本目录保留早期 `1.0.0-rc.*` 的 Release Notes、manifest 与 CycloneDX SBOM，作为项目演进与内测追溯材料。它们不删除、不覆盖，也不参与当前候选发布。

## 当前边界

- 当前候选版本为 `0.1.0`；唯一当前发布说明是 `RELEASE_NOTES_0.1.0.md`。
- `1.0.0-rc.*` 文件反映的是当时的内测构建、依赖和验收条件，不能用作 `0.1.0` 的安装包哈希、SBOM、CI 结果或发布承诺。
- `release/manifests/1.0.0-rc.*.json` 与 `release/sbom/*1.0.0-rc.*.cdx.json` 仅供历史核对，不应作为 GitHub 下载页的当前资产。
- 公开候选只可由同一 GitHub Actions 运行从对应提交产生安装包、`SHA256SUMS.txt`、SBOM、manifest、blockmap 与 Release Notes；不得复用历史本机构建资产。

## 保留与审阅规则

1. 保留历史文件的原始版本号与内容，避免改写历史证据。
2. 后续新增历史材料时，在文件名保留版本号，并在本文件补充用途说明。
3. 每次公开发布前，审阅者必须确认下载资产仅引用当前版本号；历史材料只能作为仓库文档附件。
4. 历史材料仍须通过公开树扫描；若日后发现敏感信息，应先归档到本地测试档案，再从公开仓库移除。
