# Third-party notices

No model weights, proprietary workflows, deployment credentials or operator configuration are included in the public repository.

For each GitHub release candidate, the authoritative component and dependency inventory is published as CycloneDX SBOM files in `release/sbom/`. Those inventories retain the package-supplied license identifiers for the backend, frontend and desktop dependency trees. The source repository includes only the notices required by the included source; downstream redistributors must preserve applicable third-party notices when redistributing a bundled artifact.
