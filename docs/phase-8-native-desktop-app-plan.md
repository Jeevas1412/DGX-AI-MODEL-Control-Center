# 阶段 8：独立桌面应用体验与全功能 UI 计划

日期：2026-07-20  
状态：✅ 已立项，待实施  
对应看板：C-11.0 ～ C-11.4

## 用户目标

将 DGX AI Control Center 交付为用户眼中的正常 Windows 桌面应用：双击桌面图标即可打开，安装、连接、监控、受控服务操作、日志、性能与设置全部在应用中完成。用户不需要打开浏览器、运行 PowerShell、手动启动 Vite 或复制 API 令牌。

Electron 仍使用 Chromium 渲染界面，但它是应用内部窗口，不是要求用户自行打开的浏览器。

## 运行时边界

```text
桌面快捷方式
  → Electron 主进程
      → 启动/守护本机后端
      → 持有本机会话与受保护数据
      → 托盘、登录启动、受控退出、升级恢复
  → 受保护的预加载桥
      → 仅允许结构化、白名单的 IPC
  → React renderer
      → 功能标签页与用户交互，不持有 Node、SSH、令牌或文件权限
```

- `contextIsolation` 必须开启，`nodeIntegration` 必须关闭。
- renderer 不直接读取本机令牌；桌面 API 客户端通过受限 IPC 调用主进程/后台。
- IPC 只暴露已登记的读取、计划、确认、进度与审计方法，不接受任意 URL、shell、路径、端口或环境变量。
- Web/LAN 查看模式可作为独立功能保留，但不能成为桌面应用控制功能的权限通道。

## 桌面常驻、外观语言与快捷方式

桌面应用在“设置”中提供独立的“外观与语言”“后台常驻”“快捷方式”区域。偏好由主进程原子保存到当前用户的本机产品数据目录；它们不是凭据，renderer 只能通过类型化读取/写入方法访问。

| 能力 | 首版行为 | 验收标准 |
|---|---|---|
| 后台常驻 | 提供“关闭窗口后保持后台运行”开关；首次安装默认关闭。启用后关闭窗口只最小化到托盘，主进程与回环后台继续运行；从托盘选择“退出”才完整停止。 | 连续开关/关闭窗口不会产生重复后台进程；托盘可重新显示窗口；退出后端口和子进程均退出。 |
| 显示语言 | 只支持简体中文（`zh-CN`）和 English（`en-US`）；切换立即更新窗口、导航、对话框、通知与托盘菜单，重启后保留。 | 不存在第三种可选语言、未翻译占位文本或把语言设置写入日志/审计。 |
| 主题 | 只支持深色和浅色；首次安装默认深色，切换立即应用并在重启后保留。 | 两套设计 token 覆盖窗口、弹窗、图表、禁用态与高对比焦点，不依赖浏览器主题。 |
| 快捷方式 | 安装程序提供开始菜单入口和桌面快捷方式；设置页可“创建/修复桌面快捷方式”。任务栏/开始屏幕固定仅在 Windows 允许时请求用户确认，策略禁止时显示原因。 | 快捷方式启动目标为应用 `.exe`；创建/修复可重复执行；固定失败不影响应用运行。 |

Windows 的任务栏固定需要用户确认且可能受设备策略限制，因此应用只发起受支持的请求，不承诺强制固定。详见 [Microsoft Learn：Pin your app to the taskbar](https://learn.microsoft.com/en-us/windows/apps/develop/windows-integration/pin-to-taskbar)。

## 功能标签页与后台覆盖矩阵

| 桌面区域 | 用户能完成的事 | 对应后台能力 | 安全规则 |
|---|---|---|---|
| 首次连接向导 | 保存已存在的 OpenSSH 别名、验证连接、查看兼容性 | 配置保存、固定只读验证、能力发现 | 不输入/保存私钥、密码或任意命令 |
| 总览 | 查看系统健康、资源、服务摘要与告警 | health、system、services | 只读 |
| 连接 | 管理已保存连接、复测、查看兼容性 | profiles、verify、capabilities | 仅本机操作者 |
| 服务 | 查看四项服务，创建预热/重启/停止计划、确认和跟踪进度 | local-control capabilities、plans、operations | 固定四服务；重启/停止要求空闲和二次确认 |
| 模型 | 查看 NVFP4、VLM、HY MT2 状态与受控切换计划 | 模型 metrics、HY MT2 status、未来专用事务 | HY MT2 真操作须等专用适配器验收 |
| 请求 | 查看队列、执行中请求和可解释状态 | requests、服务 metrics | 不提供任意取消命令 |
| 日志与审计 | 查询脱敏服务日志与操作审计 | logs、local audit、未来事务 audit | 不显示凭据、远端路径或原始敏感错误 |
| 性能 | 查看历史结果、对比与受控测试计划 | benchmarks、未来性能计划/进度 | 测试必须先显示限额与确认 |
| 设置 | 管理启动、通知、受保护 LAN 查看和本地数据 | app settings、LAN 配置、生命周期 | LAN 默认关闭，控制始终仅限本机 |

## 完成标准

1. 安装后从桌面入口打开单一窗口，关闭浏览器不影响使用。
2. 没有项目目录、开发 Node、Vite 或 PowerShell 前提的同类 Windows 环境可完成安装和首次连接。
3. 已交付后台功能均有对应 UI 入口、可读状态和失败说明；暂不可用能力明确显示原因。
4. 控制动作不通过文本命令输入，均显示范围、风险、前置条件、进度和审计结果。
5. 受保护数据不泄露到 renderer、日志、崩溃报告、导出或截图。

## 明确不做

- 不实现浏览器 SSH 终端、任意命令执行、任意文件编辑或 Docker 控制台。
- 不把局域网查看权限升级为远程控制权限。
- 不在 HY MT2 专用事务完成前，把 mock 按钮包装成真实控制。
- 不因桌面化而删除现有 Web/LAN 只读能力；两种访问模式必须有清晰权限边界。
