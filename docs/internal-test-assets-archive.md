# 内测固定资产归档边界

适用版本：`0.1.0` 公开候选。

历史的单机启动脚本备份、逐文件恢复、恢复前哈希校验、性能试验计划和阶段基线，属于某一内测目标的操作证据，已完整保留在本机测试环境档案中。它们不属于公开安装包、公开产品工作树或用户安装后的默认能力。

公开产品的恢复与支持边界如下：

1. 用户经界面创建并验证 OpenSSH 别名连接；
2. 用户导入、校验并激活独立审阅的目标支持包；
3. 监控、模型发现、日志与受控服务动作均只使用已激活支持包的固定合同；
4. 不提供面向未知远端路径的备份、恢复或任意远程命令入口；
5. 任何特定设备的恢复材料只可在对应内测档案中，依据单独授权使用。

这样保留了历史可追溯性，同时不让新安装环境误把某台开发设备的资产当作通用恢复目标。
