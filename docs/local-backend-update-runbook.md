# 8501 本机更新加载后的验收与回滚清单

本清单仅适用于 `127.0.0.1:8501` 的当前用户计划任务。它不改变 DGX，也不开放局域网访问。

## 何时执行

仅在当前 24 小时稳定性窗口完成并通过后执行。不要在观测期间重启 8501。

## 更新加载后验收

```powershell
cd <project-root>
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test_local_readonly_backend_deployment.ps1
```

该脚本只使用本机 GET，校验：精确 CORS、最终 health `ok`、4 项服务摘要、Benchmark 响应和 `8501` 的回环监听。图像服务为按需加载时，默认最多等待 60 秒、每 5 秒复查；首检和重试次数会打印出来。

## 计划任务重载

在用户确认维护窗口后，使用现有任务名重启本机后端，再立即运行上面的验收脚本。此步骤不应与 C-06.8 观测并行。

## 回滚门槛

若健康、CORS、回环监听或 Benchmark 合同失败：停止继续交付，保留控制台/验收输出，并仅使用事先保存的、已审阅的本机代码副本恢复。当前工作区不是 Git 仓库，因此没有已验证副本时不得猜测性覆盖代码或删除数据；应先请求新的明确授权。
