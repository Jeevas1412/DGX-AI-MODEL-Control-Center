## C-13.1 首轮公开树扫描基线

公开树扫描已在 Windows PowerShell 5.1 通过语法和执行验证，并报告 20 项候选问题。主要类型为：

- 内部任务看板、历史工作日志与运行手册中的本机绝对路径或私网地址；
- 已由 .gitignore 排除但仍留在工作区的本地前端日志；
- 必须保留的 loopback/private-network/凭据脱敏测试字符串；
- 开发 README 中的本机路径。

后续整改不会盲目删除本机证据：私有过程记录将保留在 Obsidian/本地归档，公开仓库改为去身份化说明、保留地址和测试抑制规则。

## 明确不做

- 不在此整改阶段启动、停止、重启或修改 DGX 服务。
- 不导出当前 DGX 配置、日志、截图、IP、用户目录或令牌到公开树。
- 不初始化公开 Git 仓库、不推送 GitHub、不生成或安装新的安装包。
- 不把未签名内部测试安装器视为可发布交付物。
